# React Launchpad Design System & Starter

Welcome to the interactive Storybook component catalog for **React Launchpad**.

This starter is built for teams delivering high-velocity, production-grade web applications with **zero required backend dependencies**.

## Core Architectural Principles

- **Framework Agnostic Primitives:** Powered by accessible Radix UI primitives and Tailwind CSS v4 styling tokens.
- **Type-Safe Form Contracts:** Uniform React Hook Form + Zod contracts with dynamic multi-language validation.
- **Composable Layout Architecture:** Responsive Application Shell featuring mobile sheet drawers, collapsibility, and breadcrumb slot integration.
- **Backend-Free Experience:** Deterministic in-memory adapters for authentication, tabular data, and file upload progress.
- **Strict Boundaries:** Enforced architectural boundaries between `core`, `features`, and `app`.

## Catalog Structure

- **Core Primitives:** Buttons, Badges, Inputs, Dialogs, Cards, Sheet drawers, and Command palette.
- **Forms & Fields:** Localized validation, dynamic field arrays, comboboxes, and multi-step wizard stepper.
- **Data & Tables:** TanStack Table integration, column filtering, row selection, pagination, and URL state synchronizers.
- **Files & Media:** Drag-and-drop dropzones, file validation policies, and upload queue management.
- **Advanced UI:** Sanitized rich text editors, virtualized lists for large datasets, and accessible SVG charts.
